# Factsheet: Mustache

## Gruppe: Template-Engines

## Zweck

"Logic-less" Templates. Sie erlauben absichtlich fast keine Programmierlogik in der Vorlage, was eine extrem strikte Trennung von Logik und Design erzwingt. Mustache ist der Vorgänger vieler moderner Engines.

## Reifegrad

Stabil

## Technische Schulden

Gering

## Erwartetes Lebensende

Kein EOL bekannt

```bash
sudo apt install -y node-mustache
```
