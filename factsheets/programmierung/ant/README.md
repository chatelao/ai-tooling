# Factsheet: Ant

## Gruppe: Programmierung

## Zweck

Apache Ant ist ein Java-basiertes Build-Werkzeug, das XML-basierte Konfigurationsdateien verwendet, um Build-Prozesse zu steuern.

## Reifegrad

Stabil

## Technische Schulden

Gering

## Erwartetes Lebensende

Kein EOL bekannt

## Referenzhandbuch

[Link](https://ant.apache.org/)

## Installation (Ubuntu 24.04)

```bash
sudo apt install -y ant
```

## Validierung

```bash
ant -version
```
